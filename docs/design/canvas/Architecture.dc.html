Layer rules

  • presentation → repository → Dio. Widgets never import Dio.
  • Screens switch on a sealed ApiException, never status codes.
  • 401/403 anywhere: clear token, signed out, back to Sign in.
  • 422: errors under each field; 429: countdown from Retry-After.
  • Money is an int of rupees; shown as Rs. 1,234.

Data on the phone

  • Token in secure storage only.
  • KYC images: never on disk after upload.
  • No PII in logs, analytics, crash reports or push payloads.
  • No contacts, gallery, storage or location permissions.
